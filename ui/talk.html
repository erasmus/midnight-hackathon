A consent-first talent index for people who already proved it in public.

The gap

The best people rarely sit in an applicant pile.

They are already on leaderboards, rating lists, paper graphs, and public track records. Application funnels only see the people who already decided they are founders — or who know the program exists.

Index disclosure

Competition profiles that publicly link a real-world identity: real name, bio URL, or verifiable handle reuse with a corroborating signal.

Do not unmask

No de-anonymization, no wallet graphs, no cross-referencing to recover a pseudonym. If they did not publish the join, they are not in the index.

Hard constraints

Five rules the pipeline is not allowed to violate.

  1. Consent-by-disclosure only. Enter via a public self-link. Precision over recall.
  2. Age floor 18. Birth year when the source has it; young-skew platforms need independent adulthood evidence or we drop.
  3. Top-of-tail only. Top-N ≤ 500 per source. Polite rate limits (≥1s where there is no bulk endpoint). No bulk harvest.
  4. Relevance gate. Talent without a professional/technical surface (GitHub, LinkedIn self-link, site, papers) does not rank.
  5. Humans write. Rank and explain. A person decides. Draft outreach is labeled draft.

Architecture

One schema. One orchestrator. SQLite. No infra.

adapters → normalize → resolve → enrich → score → rank → persist → shortlist + dossier

Adapters

Each source is a module: fetch_top(n) → RawProfile[]. Auto-discovered. A dead source is logged and skipped.

Identity

Only two joins: explicit self-links, and handle reuse with a corroborating signal. Uncorroborated collisions stay weak_match — never surfaced.

HTTP

One client for every request: per-host spacing, disk cache, retry-once on 5xx. Adapters do not speak to the network on their own.

Evidence is non-negotiable: every identity link records why we believe it.

Current state · live in the repo

The pipe is real. Two sources fetch. Downstream stages are wired as stubs.

Running

  • Codeforces — ratedList (exact percentiles), rating ≥ 2400, contest history on the top slice, public name / org / country.
  • Lichess — top 200 × blitz / rapid / classical, bulk user fetch, bio links, title + declared FIDE rating for a later join.
  • pipeline.py — discover → fetch → normalize → resolve → enrich → score → persist → outputs. Any stage independently skippable.
  • core.http + SQLite — rate limit, cache, idempotent upserts on (platform, handle).
  • Demo UI — shortlist, dossier (sparkline + evidence appendix), coverage, limitations. Fixture until the pipeline overwrites JSON.

Spec’d, not fetching yet

  • Kaggle (Meta Kaggle dump), FIDE rating list, Metaculus, OpenAlex, CTFtime — schema and coverage table exist; adapter modules are not in adapters/.
  • Resolve / enrich / score emit pass-through rows so a new adapter can run end-to-end tonight without waiting on Epic 3–5.
  • Composite is documented: 0.45·outlierness + 0.30·trajectory + 0.25·addressability. Scoring code is still a stub.

What a ranked row means

Outlierness × trajectory × addressability.

45% Outlierness — platform percentile on a shared scale. Codeforces is exact (rank / rated population). Others: documented rank heuristic.
30% Trajectory — 24-month rating slope where history exists; else account-age vs rank. Recency decay if inactive > 90 days.
25% Addressability — GitHub with real activity 40 · LinkedIn self-link 25 · site 20 · papers 15. Cap 100.

Multi-domain bonus +10 if top-1% in two unrelated domains (chess blitz + chess rapid = one domain). Hard filters first: age, already-founder, no professional surface.

LinkedIn is stored from a self-published URL. We do not scrape it. The human opens the dossier.

Excluded by design

The moat is not scraping.

It is the consented identity graph and a documented cross-domain normalization table. These sources stay off the list on purpose.

Polymarket & prediction wallets

Wallet-linked, pseudonymous by default. Indexing it invites unmasking.

On-chain / ENS / wallet graphs

Joining a wallet to a person is the opposite of consent-by-disclosure.

Private Discords, Telegrams, lists

Not public self-links. Out of scope.

Say this before anyone else does

Known limits of the v0.

Percentiles are a heuristic

Codeforces is exact. Everything else is rank against a published or estimated population. Cross-domain comparability is a research problem; we shipped a documented first pass.

Matching is low-recall on purpose

Twenty correct people beat two hundred with three errors. Handle collision alone is never identity.

No founder backtest yet

The obvious next experiment: take known founders and walk their public traces backward through these sources.

Fixture vs live

The shortlist on screen is labeled fixture until pipeline.py overwrites it. Do not claim placeholder names as live hits.
