# Demo script (90 seconds)

Rehearse against `ui/index.html` (fixture until pipeline overwrites `ui/data/shortlist.json`).

1. **Hook (10s)**  
   “35,000 applications, 35 seats — and the best candidates never apply, because they don’t know they’re founders yet.”

2. **Shortlist (25s)**  
   Open Shortlist. “Real people-shaped rows, six domains, one schema. Composite is 0.45 outlierness + 0.30 trajectory + 0.25 addressability. No professional surface, no rank — that’s the consent filter wearing a scoring hat.”

3. **Dossier (35s)**  
   Click row 01. Walk **achievement → sparkline → evidence appendix**.  
   “Every link here was published by the candidate themselves — we index disclosure, we don’t unmask anyone. Polymarket is on our excluded list *by design*. The outreach paragraph is a draft for a human. There is no send button.”

4. **Coverage (15s)**  
   Coverage tab. “7 adapters tonight, 22 identified, one schema. The moat isn’t scraping — it’s the consented identity graph and the cross-domain normalization table.”

5. **If asked / leftover time**  
   Limitations tab. Don’t let judges discover Gap 3 (percentiles), low-recall matching, missing founder backtest, or LinkedIn-as-link-only.

## What not to claim

- That fixture names are live index hits (banner on screen until `fixture: false`).
- That we scrape LinkedIn.
- That handle collision alone is identity.
